# Referral Reward Structure

## Summer Training Referrals

### Tier 1: First 5 Referrals
- **Reward**: ₹100 per referral
- **Range**: Referrals 1-5
- **Total Earning**: ₹500

### Tier 2: Next 15 Referrals  
- **Reward**: ₹200 per referral
- **Range**: Referrals 6-20
- **Total Earning**: ₹3,000

### Tier 3: Beyond 20 Referrals
- **Reward**: ₹200 per referral
- **Range**: Referrals 21+
- **Ongoing Earning**: ₹200 per referral

## Apprenticeship Training Referrals

### Tier 1: First 5 Referrals
- **Reward**: ₹200 per referral
- **Range**: Referrals 1-5
- **Total Earning**: ₹1,000

### Tier 2: Beyond 5 Referrals
- **Reward**: ₹500 per referral
- **Range**: Referrals 6+
- **Ongoing Earning**: ₹500 per referral

## Summary

| Training Type | 1-5 Referrals | 6-20 Referrals | 21+ Referrals |
|---------------|---------------|----------------|---------------|
| Summer        | ₹100 each     | ₹200 each      | ₹200 each     |
| Apprenticeship| ₹200 each     | ₹500 each      | ₹500 each     |

## Maximum Earning Potential

### Summer Training (First 20 referrals)
- First 5: ₹100 × 5 = ₹500
- Next 15: ₹200 × 15 = ₹3,000
- **Total**: ₹3,500

### Apprenticeship Training (First 10 referrals)
- First 5: ₹200 × 5 = ₹1,000
- Next 5: ₹500 × 5 = ₹2,500
- **Total**: ₹3,500

## Implementation Notes

- Referral counts are tracked separately for each training type
- Rewards are calculated based on the referrer's existing referral count for that specific training type
- All referrals start with "pending" status and require admin approval for payment
- Referral codes are case-insensitive and automatically converted to uppercase
